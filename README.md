# Денталь профи — сайт, страница «КТ»

Одностраничный сайт стоматологической клиники «Денталь профи» о компьютерной томографии (КТ),
свёрстанный по макету Figma. Страница адаптивная: на компьютере (от 1200 px) — раскладка десктопного
кадра макета, на планшете (768–1199 px) — планшетного, на телефоне (до 767 px) — мобильного.
Чистые HTML, CSS и немного JavaScript, без сборки и без пакетов: файлы можно править в любом редакторе.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | вся страница; в начале — комментарий «ЗАМЕНИТЬ» со всеми адресами-заглушками |
| `assets/css/style.css` | стили: цвета, шрифт, раскладка для всех ширин |
| `assets/js/main.js` | мобильное меню (кнопка-бургер) |
| `assets/img/` | готовые картинки (в 2× для чётких экранов) |
| `assets/img/src/` | исходники из Figma — на сайт не публикуются |
| `.github/workflows/pages.yml` | автоматическая публикация на GitHub Pages |
| `tools/` | проверки без браузера (Python 3, только стандартная библиотека) |

## Как открыть локально

- **Проще всего:** дважды щёлкнуть по `index.html` — страница откроется в браузере.
- **Как на настоящем сервере:** в папке сайта выполнить

  ```
  python -m http.server 8765
  ```

  и открыть в браузере http://localhost:8765/. Остановить сервер — `Ctrl+C`.

Проверки (запускать из папки сайта):

```
python tools/check_site.py
python tools/check_assets.py
```

Код возврата 0 — всё в порядке; иначе печатается список проблем. На Windows, если в выводе кракозябры,
перед командой задайте `PYTHONIOENCODING=utf-8` (в Git Bash: `PYTHONIOENCODING=utf-8 python tools/check_assets.py`).

Пересобрать картинки `assets/img/` из тайлов макета и исходников `assets/img/src/` (Windows, около 1,5 минуты):
`python tools/build_assets.py`, затем `python tools/check_assets.py`. Тайлы лежат в служебной папке
`.autopilot/<папка прогона>/design/tiles` — скрипт находит её сам, как бы она ни называлась.

## Как опубликовать на GitHub Pages

1. **Создать репозиторий.** На github.com: «+» → New repository → задать имя (например, `dental-profi`)
   → Create repository. На бесплатном тарифе GitHub Pages работает только для публичных (Public) репозиториев.
2. **Отправить код.** В папке сайта (основная ветка должна называться `main`):

   ```
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git branch -M main
   git push -u origin main
   ```

   При первом push Windows откроет окно входа в GitHub (Git Credential Manager) — войдите в браузере.
3. **Включить Pages.** В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. **Дождаться публикации.** Вкладка Actions → запуск «Публикация на GitHub Pages» должен стать зелёным
   (1–2 минуты). Если он успел упасть до шага 3 — нажмите Run workflow, чтобы запустить его ещё раз вручную.
5. **Где искать адрес.** Settings → Pages — вверху строка «Your site is live at …»; обычно это
   `https://<ваш-логин>.github.io/<имя-репозитория>/`. Тот же адрес есть в Actions → последний запуск → шаг deploy.

Дальше сайт обновляется сам: каждый push в `main` публикует новую версию. Наружу уходят только
`index.html`, `.nojekyll` и `assets/` (без `assets/img/src/`); служебные папки и этот README не публикуются.

## Что заменить

Все внешние адреса пока — заглушки-якоря. Они собраны в комментарии «ЗАМЕНИТЬ» в начале `index.html`;
заменить нужно значение `href` у соответствующих ссылок (например, `href="#telegram"` →
`href="https://t.me/имя_канала"`). Ни одного номера телефона или ника не придумано — их даёт клиника.

| Элемент | Заглушка | Что нужно от клиники |
|---|---|---|
| Пункты меню (7) | `#uslugi`, `#ceny`, `#komanda`, `#akcii`, `#otzyvy`, `#pacientam`, `#kontakty` | адреса страниц: Услуги, Цены, Команда, Акции, Отзывы, Пациентам, Контакты |
| Кнопка «Смотреть видео» | `#video` | ссылка на видео |
| Кнопка «Задать вопрос» | `#vopros` | куда вести: форма, телефон или мессенджер |
| Кнопки Telegram / WhatsApp / Max | `#telegram`, `#whatsapp`, `#max` | ссылки на аккаунты клиники |

## Шрифт

В макете гротеск, похожий на Gilroy / Proxima Nova (оба платные); на сайте — бесплатный Manrope из Google Fonts.
Заменить: строку `<link … fonts.googleapis.com …>` в `<head>` файла `index.html` и `font-family` в начале
`assets/css/style.css` (для платного шрифта — подключить его файлы по лицензии и прописать `@font-face`).
